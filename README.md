# SpecWATT

Продолжение Android-приложения Warm Graphite. React Native / Expo SDK 58, TypeScript, Expo Router; локальный FastAPI / SQLite симулятор. Это проверяемая программная основа, **не готовый аппаратный Android MVP**: APK и запуск на Android ещё не проверены.

## Запуск

```powershell
cd mobile/specwatt-app
npm ci
npm test
npm run typecheck
npm run lint
npm start
```

Откройте приложение в совместимом Expo Go или development build. Пройдите выбор языка и откройте демо. На устройстве/эмуляторе нужно проверить фактическую совместимость, запуск и все сценарии. Для просмотра React Native web: `npm run web`; web не заменяет Android-проверку.

Backend: [инструкция, API и ограничения](backend/README.md). Экран «Настройки → Серверный симулятор» подключает отдельную настоящую серверную сессию; offline demo не обращается к API. Регистрация создаёт локальный серверный аккаунт. Почтовая проверка и восстановление не подключены.

## Состав

- `mobile/specwatt-app/` — приложение, шесть экранов, onboarding, настройка приборов, RU/KY, сохранение, offline demo, серверный клиент.
- `mobile/specwatt-core/` — прежняя независимая доменная библиотека; текущий клиент использует `src/specwatt/model.ts` и её тесты.
- `backend/` — защищённый владельцем API и явно обозначенный симулятор. Не ESP32 gateway.
- `docs/` — архитектура, проверки, безопасность, ограничения и продолжение.
- `design/` — источники дизайна и сведения об assets.
- `firmware/` — требования к аппаратной интеграции; прошивка до подтверждения схемы не реализована.

## Поведение и границы

CH1 = 1,8 Вт, CH2 выключен, CH3 = 2,4 Вт: сумма 4,2 Вт. CH3 всегда защищён. Автоматика требует явного разрешения; модель учитывает лимит, свежесть, ручной приоритет и временное окно. План 8,4 → 6,6 Вт представляет прогноз демонстрационных задач; применение сохраняет расписание, но не выполняет его по часам. Перенос не обещает снижение кВт·ч.

Физический контроллер, ESP32, облако, фоновые задачи, push и production deployment не подключены. Политика и условия в UI — черновики без юридической проверки. Перевод KY требует проверки носителем. Фотокаталог сохранён из проекта, но не все фотографии совпадают с приложенными макетами.
