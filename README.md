# SpecWATT

**Мониторинг энергопотребления, объяснимый автопилот и безопасное управление разрешёнными нагрузками.**

> **Статус: инженерный прототип / MVP в разработке.** Это не сертифицированное устройство для бытовой электросети и не готовый коммерческий Android-релиз.

**Инициатор идеи и руководитель проекта:** [@t1ktakdev](https://github.com/t1ktakdev)  
**Разработка:** команда SpecWATT, Бишкек, Кыргызстан.

SpecWATT создаётся для того, чтобы пользователь мог видеть измеренную нагрузку, понимать причины пиков потребления и безопасно планировать работу подключённых приборов. Продукт состоит из Android-приложения, локального сервера и контроллера ESP32.

**[Открыть текущую интеграционную ветку → integration/unified-v7-20261027](https://github.com/t1ktakdev/SpecWatt/tree/integration/unified-v7-20261027)**

## Три части системы

| Компонент | Технологии | Назначение |
|---|---|---|
| **SpecWATT App** | React Native, Expo SDK 58, TypeScript | RU/KY, устройства, графики, автопилот, расписания, история, настройки |
| **SpecWATT Brain** | Python, FastAPI, SQLite | Учёт пользователей, изоляция контроллеров, команды, расписания, проверки безопасности и симулятор |
| **SpecWATT Grid** | ESP32, USB-C / CH340 | Разрабатываемый низковольтный контроллер; интеграция с датчиком измерений — следующий этап |

## Что уже проверено

- **App:** переработанный интерфейс Warm Graphite, SVG-иллюстрации устройств, демонстрационные экраны, серверный workspace, RU/KY и тесты.
- **Brain:** аутентификация, защита данных разных пользователей, статусы команд, безопасная обработка неопределённого исхода, расписания, CH3 — защищённый канал.
- **Grid Stage 0:** по результатам стендового испытания 28.10.2026 прошивка ESP32 успешно записана; команды `PING`, `INFO`, `STATUS` отвечают через `COM8`. Предварительно сделана и проверена локальная резервная копия 4 МиБ flash. **Сборка Stage 0 и логи находятся отдельно на компьютере, а не в текущей исходной ветке репозитория.**
- **Проверки интеграции:** [GitHub Actions — последняя принятая UI-волна](https://github.com/t1ktakdev/SpecWatt/actions/runs/40699574986), завершено успешно по всем пяти security jobs.

## Честные ограничения

- Основные экраны приложения пока используют **DEMO**, а полноценное объединение их состояний с FastAPI предстоит реализовать.
- Серверные контроллеры помечены как **simulator**. Показанные в них ватты не являются измерениями датчика.
- ESP32 Stage 0 пока **не измеряет электроэнергию и не управляет GPIO**. Датчик INA219 заказан; физические измерения требуют отдельного испытания.
- **CH3 защищён:** команды управления этим каналом недопустимы.
- Нативная Android-приёмка, TalkBack и работа нативного выбора фотографий ещё не подтверждены.
- Известные зависимости с security advisories документированы; успех baseline gate не означает нулевой риск.
- Никаких обещаний измерения всех приборов по одному датчику или подключения экспериментального стенда к 220 В.

## Запуск для разработки

Для актуального кода сначала переключитесь на [интеграционную ветку](https://github.com/t1ktakdev/SpecWatt/tree/integration/unified-v7-20261027).

```powershell
cd mobile/specwatt-app
npm ci
npm test
npm run typecheck
npm run lint
npm run web
```

Сервер и его контракты: [backend/README.md](backend/README.md). Режим WEB удобен для проверки интерфейса, но не заменяет Android-эмулятор или аппаратные испытания.

## Ближайшие этапы

**Stage 1:** защищённый локальный диагностический мост ESP32 ↔ Brain, с честной маркировкой симуляционных данных и проверкой обрыва связи.  
**Stage 2:** измерения через INA219 на безопасном стенде 5 В.  
**App:** подключение главных экранов к состоянию сервера и нативная Android-приёмка.
