# Оставшиеся ограничения

1. **Native Android не проверен.** Нет доказательств рендера, TalkBack, системного fontScale, клавиатуры, safe areas или native Reduce Motion на эмуляторе. Android JS/Hermes export успешен, но не заменяет APK/native acceptance. Физический телефон не использовался.
2. **Expo Doctor: exit 1, 19/20.** Тринадцать пакетов SDK 58 отстают по patch-версиям. Массовое обновление не выполнялось; exclude/ignore не добавлялись. Нужен отдельный проверенный dependency upgrade.
3. **npm audit: exit 1.** Девять vulnerable package entries: 4 high, 5 low; в `via` три прямые уникальные advisory. Существующий baseline-check — exit 0, это не отсутствие уязвимостей. JSON сохранён целиком; baseline и scanner allowlist не менялись.
4. **SIMULATOR, а не аппаратная телеметрия.** INA219 не интегрирован. Все W/Wh в новом пространстве относятся к серверному симулятору. `hardware_transport:false` сохранён. ESP32 Stage 1, firmware, USB, COM и 220 В не затрагивались.
5. **Сеанс/выбор.** Выбранный контроллер хранится только в памяти и выбирается заново из owner-scoped списка. WEB токен исчезает при полном reload. На native используется существующий SecureStore; восстановление нестандартного base URL после перезапуска пока не реализовано — стартовая проверка использует штатный адрес.
6. **История ограничена.** Страница — 100 событий/образцов; workspace держит последние 500, график — последние 30 допустимых образцов. Следующая страница загружается через refresh/явную кнопку. Не реализованы часовые агрегаты, экспорт истории и большой виртуализированный журнал. События старше последних 100 команд могут не иметь доступного origin для фильтра «Ручные». Часть редких backend reason/kind показывается техническим кодом.
7. **Планирование — реальный существующий scheduler, но форма пока инженерная.** Ввод начала в ISO UTC; записи показаны в часовом поясе пользователя. Нет автоматического глобального `enabled`, native date/time picker, аппаратного выполнения или автозапуска worker. Все create/cancel/tick выполняются явно.
8. **Назначения.** Текущие имена, комнаты и curated SVG берутся из snapshot; разрешение автоматизации меняется через API. Нового редактора имени/комнаты и настоящего pairing в этой волне нет. Пользовательские фото остаются в прежнем DEMO-механизме; серверный API не предоставляет загрузку фотографий.
9. **Аналитика.** Wh — трапецеидальная оценка только покрытых интервалов симулятора, с границей разрыва 60 с. Нет тарифов, денежных «сбережений», прогнозной точности или заявлений о потреблении здания. Это намеренные ограничения достоверности.
10. **WEB text enlargement — приближение.** Снимки 1,3×/1,5× масштабируют вычисленные CSS-размеры текста и не доказывают native fontScale. Навигация адаптируется при переносе подписей. Полная нативная приёмка по матрице остаётся обязательной.
11. **Предупреждения среды.** Starlette/httpx deprecation, Node MODULE_TYPELESS_PACKAGE_JSON, существующий цикл API ↔ scheduler, development warnings Reduce Motion/NO_COLOR. Bandit medium+ — exit 0, но сообщает существующую аннотацию `nosec B608` без соответствующей находки. Предупреждения не скрывались изменением gate.

P0 и основной P1 реализованы и проверены в WEB/HTTP. P2 выполнен для основного серверного пути и честной истории; это не финальная нативная/производственная приёмка всего продукта. Draft PR можно готовить из локальной ветки после разрешения на публикацию; push/PR/merge не выполнялись.
