## Validation and limitations

Baseline before integration: 55 mobile tests, TypeScript/lint and 19 backend tests passed; original Security 83 and Scheduler clone 58 also passed. These baselines did not prove integration.

Merged verification and artifact locations are recorded in [INTEGRATION-RESULTS-2026-10-27.md](INTEGRATION-RESULTS-2026-10-27.md). Initial wrong-directory backend invocation failed imports and was corrected to documented backend working directory. HTTP smoke initially asserted a numeric tick count; real tick contract is an array and the assertion was corrected. Both failures were test invocation/contract assumptions, not hidden successful results.

SEC-002 mitigation trusts owner-provided simulator acquisition metadata. It is not authenticated hardware telemetry. Correlation outside the strict recovery window remains unresolved and needs operator recovery, not a fabricated success. Worker does not refresh stale samples or acknowledge commands. Cancellation after acknowledged start can leave a load on. See [security findings](../security/docs/findings.md).

All six main approved screens still use the offline demonstration store. The separately labelled server workspace now performs actual authenticated simulator commands and scheduling. Routing a selected server controller through all six Warm Graphite screens, with coherent error/offline state, remains a Codex integration task; do not label the offline screens live.

The initial local home capture still showed obvious photo/spacing differences despite the root layout fix. Further reference-alignment changes and their browser evidence are recorded separately. Android Safe Area, font scaling, keyboard/back, native SVG gradients, cancelled gestures, TalkBack and sustained frame times require a future authorized device/emulator pass. This PR must remain draft until those acceptance checks and the main-source integration are reviewed.
