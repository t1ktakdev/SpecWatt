# Как открыть и проверить SpecWATT

Проверенная ветка: `codex/product-finish-20261029`.
Worktree: `C:\Users\user\.codex\worktrees\specwatt-product-finish-20261029\SpecWATT`.

## Быстрый просмотр

Пока запущенные этой сессией процессы работают, откройте **http://localhost:8125**. API работает на **http://127.0.0.1:8000**, `GET /health` сообщает `hardware_transport:false`.

Это настоящий WEB-клиент Expo и настоящий локальный FastAPI/SQLite; измерения создаёт серверный симулятор. Это не APK и не подключение ESP32.

## Повторный запуск

Первый PowerShell — API, из корня нового worktree:

```powershell
Set-Location 'C:\Users\user\.codex\worktrees\specwatt-product-finish-20261029\SpecWATT'
$env:SPECWATT_DB = Join-Path (Get-Location) 'outputs\product-finish\preview.sqlite3'
$env:SPECWATT_CORS_ORIGINS = 'http://127.0.0.1:8125,http://localhost:8125'
$env:SPECWATT_SCHEDULER_ENABLED = '0'
python -m uvicorn backend.specwatt_api.app:create_app --factory --host 127.0.0.1 --port 8000
```

Второй PowerShell — приложение:

```powershell
Set-Location 'C:\Users\user\.codex\worktrees\specwatt-product-finish-20261029\SpecWATT\mobile\specwatt-app'
# Зависимости уже установлены; для чистой установки используйте npm ci.
$env:NODE_OPTIONS = '--use-system-ca'
npx expo start --web --host localhost --port 8125
```

Если порт занят именно уже запущенным предпросмотром, используйте существующую страницу. Не завершайте чужие процессы. Для остановки своего процесса — Ctrl+C в его терминале. Созданная SQLite остаётся локально; удалять её для восстановления не нужно.

## Пятиминутный сценарий

1. Выберите RU или KY. Пройдите вводные экраны. DEMO работает локально; серверное пространство открывается через подключение контроллера / «Настройки → Серверный симулятор».
2. На серверном экране оставьте `http://127.0.0.1:8000`. Зарегистрируйте **свой временный тестовый аккаунт**: адрес с доменом `.test`, новый пароль 12–128 символов. Проверка почты и восстановление пароля не реализованы; не используйте реальный пароль.
3. Создайте серверный симулятор. Главная показывает 4,2 Вт, предел 7 Вт и запас 2,8 Вт. Подпись прямо сообщает, что это симуляция.
4. Откройте «Устройства». CH1: запросите выключение. Состояние станет «Запрошена», прежние 1,8 Вт ещё не означают выключение. Выполните отдельный шаг симулятора. Только после этого появятся подтверждение и CH1 = 0 Вт. CH3 остаётся защищённым во всех вкладках.
5. В «Автопилоте» разрешите автоматизацию CH2: сначала откройте объяснение, затем подтвердите разрешение. CH3 не получает такой кнопки.
6. В «Плане» выберите CH2, «Через 15 мин», длительность 1 минуту. Проверьте окно, посмотрите местное время/часовой пояс и UTC. Подтвердите создание; отмените сохранённое расписание отдельным подтверждением. Создание расписания не означает ACK команды. Проверка наступивших окон и шаг симулятора — разные явные действия.
7. В «Журнале» раскройте историю выполнения и сведения о событии. Проверьте фильтры. Старые записи подгружаются ограниченными порциями; нет синтетических событий.
8. Через 30+ секунд без нового образца данные устареют: вместо актуальной мощности будет «—», команды будут недоступны. Кнопка чтения не обновляет время измерения. Создайте новый образец симулятора явно.
9. Для проверки сети остановите **свой** API, обновите данные: приложение покажет ошибку и отключит команды. После запуска API повторите чтение. Не повторяйте команду с неизвестным исходом — сначала сверяйте историю.
10. Вернитесь в DEMO: серверные числа/команды не попадают в локальное демо. В WEB токен хранится в памяти: после перезагрузки страницы потребуется вход и повторный выбор контроллера.

## Повтор проверок

Из `mobile/specwatt-app`: `npm test`, `npm run typecheck`, `npm run lint`.

Для Playwright установлен модуль:

```powershell
$env:PLAYWRIGHT_MODULE = 'C:\Users\user\AppData\Local\npm-cache\_npx\9833c18b2d85bc59\node_modules\playwright'
$env:QA_BASE_URL = 'http://localhost:8125'
$env:QA_OUTPUT = '../../outputs/product-finish/recheck-web'
node --experimental-strip-types scripts/live-ux-smoke.mjs
```

Скрипт сам создаёт и останавливает свой отдельный FastAPI с временной БД и синтетическими аккаунтами. Ваш API на 8000 он не трогает. Нужен установленный Edge Chromium. Отсутствующие зависимости не превращаются в успешный результат.

Экспорты: `npm run export:web -- --max-workers 2`, `npm run export:android -- --max-workers 2`. Android export — JS/assets, не native acceptance и не установленный APK.
